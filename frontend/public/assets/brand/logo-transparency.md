# Transparent JE-Inspi logo

Created with the built-in image generation tool. A clean foreground rendition was used after the original extraction left background speckles. The PNG has genuine alpha transparency. Both apps use the asset without a CSS background panel; hero imagery uses white lettering via a CSS filter and light screens use sage lettering.

## Final prompt

Use case: logo-brand.
Create one clean logo on a genuinely transparent background, not a mockup.
Render exact main text "JE INSPI" in elegant thin high-contrast Didot-style serif lettering. Render exact small subtitle "DIAMANT JUWELIER" centered underneath, in tracked uppercase serif lettering. Main N has a graceful curved sweeping diagonal extending underneath toward the right. Above the N shoulder place a small brilliant diamond drawn with simple crisp facet lines and two tiny four-point sparkles.
All visible logo shapes are one uniform dark sage green #6B8965. Solid smooth precise typography, vector-like clean artwork, no texture, no distress, no photography, no shadows, no noise, no border, no rectangular colored background, no extra words.
Wide horizontal approximately 2.5:1. Compact margins. Preserve all lettering and diamond fully within image bounds. Everything outside logo strokes, including letter counters and spaces inside the diamond, must be fully transparent.
This is the transparent cutout version of a luxury jeweller's existing ivory logo. The consuming website will color the visible logo strokes ivory using CSS.
